## Description

Site vitrine complet de la conférence tech panafricaine **AfriConnect Summit**, un événement annuel réunissant développeurs, entrepreneurs et investisseurs du continent africain. Le site est moderne, responsive, avec dark mode, animations fluides et navigation intuitive.

## Technologies utilisées

- **HTML5** sémantique (header, nav, main, section, article, footer)
- **CSS3** avancé (Flexbox, Grid, Variables CSS, Animations, Transitions, Media Queries)
- **JavaScript vanilla** (DOM, IntersectionObserver, localStorage, validation, filtres, onglets)
- **Google Fonts** : Space Grotesk (titres) + Inter (corps)
- **Bootstrap Icons** via CDN
- **Git & GitHub Pages** pour le versioning et le déploiement

## Fonctionnalités JavaScript implémentées

1. **Dark Mode / Light Mode** — Toggle avec persistance via localStorage
2. **Navbar dynamique** — Changement de style au scroll + menu hamburger mobile
3. **Animations au scroll** — IntersectionObserver pour fade-in, slide-in, zoom-in
4. **Compte à rebours** — Temps réel jusqu'à la date de la conférence
5. **Compteurs animés** — Incrémentation des chiffres clés au scroll
6. **Onglets du programme** — Planning par jour sans rechargement
7. **Filtrage dynamique** — Intervenants filtrés par thématique
8. **Validation de formulaire** — Validation complète avec retour visuel
9. **Bouton retour en haut** — Apparition après 300px de scroll
10. **Année dynamique** — Copyright mis à jour automatiquement
